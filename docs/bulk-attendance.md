# Department attendance entry / edit

**Missing punches and afternoon attendance:** Imported single-punch rows, morning departures on day shifts, and afternoon arrivals on morning shifts start as **Needs review — choose status**. An empty `LogTime` is accepted as missing evidence: no time is invented and any existing reviewed time/minutes are preserved. Absence-report rows also start as Needs review because missing punches alone do not prove absence. These are unsaved drafts; they cannot be saved with an unresolved status. Raw punch uploads still require a real timestamp and direction.

HR checks the actual arrival/departure, missed-punch evidence, approved permission/leave and attendance entitlement, corrects times/minutes where supported, then deliberately chooses Present, Half day, Absent / unpaid or Approved holiday and records the reason. An afternoon arrival is a warning, not an automatic half-day rule; noon only identifies a review case for shifts starting before noon. Choosing Half day uses the existing attendance/payroll treatment and excludes that date from monthly late penalties. The review checks column updates with row edits. Completing a missing pair does not silently approve a row already marked Needs review. No pending status is added to the database; the existing server rejects blank/unknown attendance statuses.

**Early-going report:** Open **Attendance → Upload early-going report**, choose department/date, load staff, then upload a CSV with `Log Date,Emp ID,Emp Name,Shift End,LogTime`. The optional `From Date,01-09-2026,To Date,30-09-2026,` row and blank rows are supported. Dates accept `12-Sep-26`, `12-09-2026` or `2026-09-12`; times accept AM/PM or 24-hour values with seconds. Save Excel files as CSV. Maximum 1,000 rows / 2 MB; review/save one department/date at a time.

Emp ID matches the exact Biometric staff ID, including leading zeros. Employee name and assigned shift end must match Staff Master. Duplicate employee/date rows, unknown IDs, invalid dates/times, dates outside employment/report range, departures after shift end and overnight shifts reject the report. Existing absent, half-day and holiday attendance requires manual review, as does a departure at or before the recorded arrival. Check morning departures and missing arrivals carefully: a single log does not establish full-day attendance.

The upload stages departure time (with seconds) and completed early minutes minus the staff member's configured daily early grace, floored at zero. For example, 14:20:00 minus 14:17:31 is 2 whole minutes before grace; a 3-minute grace reduces it to zero. Original times and grace are recorded in the note. Existing arrival times, raw late minutes and edits already staged in the form are preserved. Late and early reports can be reviewed together for the same staff/date. Uploading alone writes nothing; Save uses the existing atomic attendance API and its permission, tenant, stale-data, payroll-lock and completed-review protections. Early going does not consume the monthly 25-minute late allowance or automatically create salary/leave deductions.

For a biometric **absence report**, use **Attendance → Upload absence report**. Save the spreadsheet as CSV with the exact headings `Date,Emp ID,Emp Name,Department,Shift`. For example: `04-Sep-26,1,T R UDAYA KUMARI,Pre Primary,General-1`. Blank rows are ignored; dates also accept `YYYY-MM-DD` (two-digit years mean 2000–2099). Keep Emp ID as text, including leading zeros. XLSX files are not supported.

Choose the report's department and date, load staff, then upload the CSV. Emp ID matches the exact **Biometric staff ID**, not the staff code. The employee name, department and assigned shift must also match Staff Master; inactive staff, dates outside employment, duplicate employee/date rows and unknown IDs reject the report. Maximum 1,000 rows / 2 MB. Only rows for the loaded department/date are selected; the preview counts rows for other groups. Review and save each department/date separately.

Matching absence-report rows are staged as **Needs review**, with empty times and zero late/early minutes. Review missing punches, approved leave, holidays and existing attendance before choosing a status; correct draft times/minutes for verified attendance, deselect any exceptions, and enter a review reason. Saving replaces selected daily attendance through the existing atomic bulk save, including its permissions, stale-data, locked-payroll and completed-late-review checks. Report shift names never change staff shifts. Existing notes retain a report reference; raw punches, leave balances and unselected staff are unchanged. Uploading alone writes nothing.

Open **Attendance → Attendance bulk edit — department** as HR, Principal, President or Administrator.

1. Choose a department and date, then select **Load staff & attendance**.
2. Select individual staff or all loaded staff.
3. Edit each selected row: status, in/out times, raw late minutes, early-going minutes, calculation from shift, next-day out and row note.
4. Enter a review reason and save.

The editor loads the complete department/date directly from the server rather than using the recent 150-record list. It includes active staff whose employment dates cover that day. Existing values are prefilled. Unselected staff and other dates are unchanged. Changing department/date clears the draft.

Existing minutes are preserved by default. Tick **Calculate from shift** to use the staff member's current assigned shift and entered in/out times; both times are required. Use **Next-day out** for overnight duty. Shift calculation retains raw lateness for the 25-minute monthly allowance; daily early-going grace remains separate. This edits reviewed attendance, not biometric punch records.

One save is atomic for up to 500 selected staff. Each attendance write follows the existing permissions, employment-date, locked-payroll and completed late-review checks. Reopen a completed late review through the existing authorized workflow before editing its attendance. This feature never unlocks payroll or reopens reviews automatically. Changed attendance or staff/shift data requires reloading before save. Retrying the same saved request does not write twice. The review reason and row note are recorded with attendance and the batch is audited.

Employee search filters loaded rows by name, staff code or employee reference (case-insensitive; multiple words must all match). **Select / clear all matching staff** affects only visible matches. Search keeps edited values and existing selections. The count identifies selected staff hidden by search; all selected staff are included when saving. Use **Clear all selections** to deselect visible and hidden staff, or clear the search to see the full loaded department again.
