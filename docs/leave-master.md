# Leave Master

Open **Leave & approvals → Add leave type**. HR, Principal, President and Administrator can create or edit company leave types. Staff can read their company rules and apply for active types through their own login.

Entry fields:

- Code: unique within the company, 1–16 letters/numbers/underscores, starting with a letter; normalized to uppercase.
- Leave name and annual entitlement (0–366 days, in half-day steps).
- Paid/unpaid classification, fixed after creation to preserve historical payroll and balance accounting. Create a new code for a different classification.
- Allow half-day requests, optional maximum working leave days per request, and active/inactive status.
- Policy notes for eligibility, accrual, expiry and carry-forward.

Use **Edit** beside an existing rule. Codes remain fixed. Set a type inactive to remove it from new applications; existing requests can still be approved, rejected, withdrawn or cancelled through the assigned approval office. Rule changes apply to new applications, not existing request units.

Annual entitlement and policy notes do not automatically credit, accrue, expire or carry forward staff balances. Use **Credit / adjust balance** with a reason for reviewed credits/debits in half-day steps. Only paid types accept balance adjustments. Custom paid leave appears in the balance summary, and approval/cancellation posts the existing debit/refund ledger.

The maximum counts company working days excluding configured holidays. Half-day requests must use one working date. Existing teacher/staff → Principal, Principal → Director, Director → President and support staff → HR approval routing remains in effect.
