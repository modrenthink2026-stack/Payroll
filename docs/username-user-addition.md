# Add users by username

Payroll Manager assigns a unique name-based username when the Staff Master record is saved. Duplicate names receive distinct suffixes. Add Staff shows the username and does not request a login email address. Personnel email remains contact information.

1. Create the Staff Master record.
2. Activate the staff login and share its username privately.
3. With full company access, open **Company settings → Add user / assign role**.
4. Select the activated username and the authorized role, then Save.

The list shows username, staff name and employee reference/code to distinguish similar names. Only active linked staff in the current company are available. Existing staff usernames and passwords remain unchanged. New staff still set a personal password at first login. Existing email-based accounts retain their authentication compatibility.
